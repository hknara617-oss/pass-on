# Production recovery source

This repository restores the maintainable PASS ON application source, including:

- Next.js routes for login, recovery, password update, capture, archive and account security
- Supabase cookie, PKCE and RLS-backed data access helpers
- Recovery email template for Supabase
- Local verification scripts and GitHub Actions workflow
- Production deployment and Auth configuration documentation in the root README

Operational audit evidence is intentionally excluded from this public source repository.
